HOW TO ADD YOUR OWN PRODUCT PHOTOS
====================================

This folder currently has a placeholder image for each compound:

  retatrutide.jpg
  cagrilintide.jpg
  mots-c.jpg
  bpc-157.jpg
  tb-500.jpg
  ghk-cu.jpg
  pt-141.jpg
  semax.jpg
  selank.jpg
  dsip.jpg

To use your own photo for a compound:
  1. Rename your photo to match the filename above exactly
     (e.g. your BPC-157 vial photo -> bpc-157.jpg)
  2. Replace the placeholder file in this folder with your photo.
  3. Commit/upload the change on GitHub — the site will pick it up
     automatically, no code changes needed.

If you'd rather use a different filename or add a new compound entirely,
open js/main.js and edit the "compounds" list near the top — each entry
has a "name", "cat" (category), and "img" (file path) field.

Recommended photo size: roughly 800x600px or similar 4:3 ratio,
so it fills the image slot cleanly without cropping oddly.
